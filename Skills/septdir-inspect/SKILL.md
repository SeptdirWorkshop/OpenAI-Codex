# Инспекции

Из задачи или вызова навыка брать абсолютный путь к корню проекта, открытого в IDE, и список путей файлов относительно
этого корня. Разрешения и работа с MCP — в корневом `AGENTS.md` этого проекта.

* Для каждого файла вызывать `get_file_problems` выбранного сервера с `errorsOnly: false`;
  параметры — по актуальной сигнатуре инструмента.
* При сбое MCP или отсутствии его инструментов следовать AGENTS.md;
  невыполненные инспекции вернуть с причиной, не считая их успешными.
* Возвращать все полученные замечания без фильтрации по уровню.
* При устаревшей или противоречащей текущему коду диагностике один раз открыть файл через `open_file_in_editor`
  выбранной IDE и повторить инспекцию этого файла. Если актуальность не подтверждена, отметить проверку как
  незавершённую; пустой список при известной ошибке не считать успехом.
* `timedOut: true`, `notAnalyzedReason`, усечённый ответ и неподдерживаемый файл отметить как незавершённую проверку.
* Кратко вернуть замечания с уровнем, текстом, файлом и строкой; отдельно указать непроверенные файлы и причины.
  Диагностика относится к рабочим файлам, а не Git index.
