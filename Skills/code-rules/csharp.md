# Правила C#

## Контракты и типы

* Не ставить `sealed` по умолчанию.

## Импорты

* Предпочитать импорт namespace длинному списку символов: `using App;`.

## Имена

* Методы — `PascalCase`: `Get`, `Set`, `Add`, `Run`.

## Читаемость

* У `if/else` обязательны фигурные скобки, тело — с новой строки, включая ранние `return` и `throw`.
  Фигурные скобки ставить на отдельных строках.
  Короткий тернарник допустим: `var x = (count == 2) ? 1 : 10;`; длинный — с переносом ветвей `?` и `:`.
* Короткие свойства и методы можно писать через `=>`.
