# Правила PHP

* Методы называть в `camelCase`.
* Фигурные скобки методов и управляющих конструкций ставить на отдельных строках, тело — с новой строки.
  У `if/else` скобки обязательны, включая ранние `return` и `throw`.
* Связанные присваивания выравнивать по `=` и отделять от следующего смыслового блока пустой строкой.
* Короткий тернарник допустим: `$x = ($count == 2) ? 1 : 10;`; длинный — с переносом ветвей `?` и `:`.
