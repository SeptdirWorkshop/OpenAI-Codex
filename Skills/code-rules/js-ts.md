# Правила JS/TS

## Импорты

* Когда нужны многие связанные функции и типы одного модуля, использовать `import * as Name`.
* Один класс, готовый объект или несколько отдельных символов импортировать напрямую — по реальному экспорту:
  `import Name` или `import {Name}`. Не добавлять лишний уровень вроде `Events.EventsUtil`.

## Имена

* Методы — `camelCase`. Для DOM-элементов использовать `el_`; остальные локальные имена — в стиле соседнего кода.

## Читаемость

* У `if/else` обязательны фигурные скобки, тело — с новой строки, включая ранние `return` и `throw`.
  Короткий тернарник допустим: `var x = (count == 2) ? 1 : 10;`; длинный — с переносом ветвей `?` и `:`.
* Рабочие переменные объявлять через `let`, даже без повторного присваивания.
  `const` использовать для констант программы.
* Связанные объявления как `let`, так и `const` объединять через запятую;
  каждое последующее объявление — с новой строки.

  ```js
  let el_form = document.querySelector('form'),
      data = new FormData(el_form);

  const MIN_SIZE = 10,
        MAX_SIZE = 100;
  ```
