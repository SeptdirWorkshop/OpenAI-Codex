# Правила Python

* Функции, методы и переменные называть в `snake_case`.
* Много связанных функций и типов использовать через `import module`: например, `import app` и `app.forms.get_value`.
  Отдельные классы и функции можно импортировать напрямую: `from module import name`.
* При переносе параметров и аргументов выравнивать продолжение по началу списка.
  Не раскладывать читаемый вызов по одному аргументу на строку автоматически.
* Типы записывать через встроенные коллекции и `|`: `dict[str, Any]`, `str | None`.
